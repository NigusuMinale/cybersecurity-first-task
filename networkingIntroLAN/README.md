# Intro to LAN

## Introduction
TryHackMe Intro to LAN is a beginner-level lab that explains how local area networks work and why they are important in cybersecurity. The lab introduces key concepts like network topologies, switches, routers, ip addresses, and mac addresses.

## Lab overview
- Learn how devices connect inside a local area network (LAN)
- See how switches forward traffic within the same network
- Understand how routers connect different networks and enable communication beyond the LAN
- Explore common LAN topologies such as star and bus
- Review how ip and mac addresses identify devices on the network

## What I gained from the lab
- a clearer view of how private network devices communicate
- an understanding of switch behavior and why switches are used in LANs
- the role of routers in joining separate networks and managing traffic
- insight into network discovery and how devices are found on the LAN
- practical awareness of why topology affects network performance and security

## Key concepts
. LAN stands for Local Area Network, a private network in a limited area.
. switches forward traffic using mac addresses between connected devices.
. routers connect different networks and route packets based on ip addresses.
. topology defines how devices are arranged and how traffic moves.
. ip addresses identify hosts logically, while mac addresses identify physical network interfaces.
. private network design is important for local security and efficient communication.

## Topology concepts
- star topology: all devices connect to a central switch or hub, making it easier to manage and troubleshoot.
- bus topology: devices share a single communication line, which is simple but can become slow and unreliable with many devices.
- ring topology: devices are connected in a circular path where each device passes data to the next.
- mesh topology: devices connect directly to multiple other devices, providing redundancy and better fault tolerance.
- hybrid topology: a combination of two or more topologies, used to balance performance, scalability, and security.

## conculusion
TryHackMe Intro to LAN is a useful introductory lab for anyone starting with network fundamentals. It helps build the foundation needed for cybersecurity tasks like network discovery, traffic analysis, and understanding how local network devices work together.
