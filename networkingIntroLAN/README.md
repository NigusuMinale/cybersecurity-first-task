## Key concepts
. LAN stands for local area network it is a private network in a limited area.
.switchs forward a traffic using MAC addresses between connected devices.
. routers connecte different networks and route packates based one IP addresses.
. topology is how devices are arranged and how traffic moves.
.IP addresses identify hosts address logically and MAC addresses identify physical network interface.
. private network design is very useful for local security and efficient communication. 

. star topology: all devices connect to a central switch or hub making it easier to manage.
. bus topology: devices share a single communication line which is simple but can become slow and unreliable with many devices.
ring topology: devices are connected in circular path where each device passes data to the next.
mesh topology:device connectes directly to meltipl other devices for better fault tolerance.
. hybrid topology:a combination of two or mor topologies used to balance performance scalability and security.
